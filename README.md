# 📢 Cschool Feedback & Roadmap

Bienvenue sur le dépôt **officiel des suggestions, feedbacks et roadmap de Cschool** 🎓  
Cschool est une plateforme SaaS de gestion scolaire moderne et simple d’utilisation, pensée pour les établissements, enseignants et administrateurs.

👉 **Ce dépôt n’héberge pas le code source de Cschool.**  
Il sert uniquement à :
- Collecter vos **idées de fonctionnalités** 💡
- Recevoir vos **retours utilisateurs** 🗣️
- Centraliser les **rapports de bugs** 🐛
- Partager la **roadmap publique** 🚀

---

## 🛠 Comment contribuer ?

1. **Vérifiez** si une issue similaire existe déjà (dans [Issues](../../issues)).
2. **Ouvrez une nouvelle issue** en choisissant le bon template :
   - `Bug Report` → pour signaler un problème
   - `Feature Request` → pour proposer une nouvelle fonctionnalité
   - `General Feedback` → pour partager vos idées ou suggestions générales
3. **Soyez précis** :
   - Décrivez le problème / l’idée
   - Expliquez pourquoi c’est utile
   - Ajoutez des exemples si possible

## 🏷️ Labels

Nous utilisons des labels pour organiser les issues :  
- `bug` : problème technique ou fonctionnel  
- `feature` : nouvelle fonctionnalité proposée  
- `idea` : idée générale à explorer  
- `discussion` : sujet ouvert à débat  
- `roadmap` : élément intégré dans la feuille de route
